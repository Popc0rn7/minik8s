  建议最小验收顺序

  1. kubectl get nodes
  2. 创建三容器 Pod，测 localhost 和共享 volume
  3. 测同节点/跨节点 Pod IP 通信
  4. 创建 Deployment，删除 Pod 验证自愈
  5. 创建 Service，测 ClusterIP 访问
  6. 用 ipvsadm 验证 Service 转发和负载均衡
  7. 创建 HPA，用 stress 触发扩缩容

  这套列表如果都能过，你的 minik8s 已经覆盖了调度、Pod 生命周期、CNI、Service、kube-proxy/IPVS、metrics 和
  autoscaling 这些核心路径。
